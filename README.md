# Pasapalabra 

Para preparar el entorno:
```shell
npm install
```
para ejecutar de forma rápida:
```shell
npm run start
```
Se piensa migrar después a pnpm para mejor gestión de paquetes.

## Tecnologías

**clientes**: HTML - CSS - JavaScript

**servidor**: Node.js - ExpressJS - WebSocket
